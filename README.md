# The Office Printer Knows

Entry for the make.fun bounty [The Funniest Office Joke, Judged Head to Head](https://make.fun/bounty/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c).

A tiny Python program that writes one short office joke to `/output/entry.txt`, where a head-to-head judge model compares it against the rest of the field.

```sh

```

Writes the joke to `/output/entry.txt` (UTF-8, one line, 1–200 characters).
